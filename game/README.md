# Game Runtime Decisions

이 문서는 `game/` 런타임(엔진) 쪽 **확정된 협업 계약**이다.  
채보 포맷은 [`../format/SPEC.md`](../format/SPEC.md) / [`../format/chart.schema.json`](../format/chart.schema.json)이 단일 소스이며, 엔진은 이를 변경하지 않는다.

## 역할 분담

| 역할 | 위치 | 책임 |
|------|------|------|
| 채보 작성 | `format/` 계약 준수 JSON | 차트와 `meta.audio` 상대경로 작성. Godot을 몰라도 된다. |
| 게임 런타임 | `game/` | 받은 차트를 로드·플레이한다. 점수·판정·입력·연출은 여기만의 책임이다. |

- 엔진은 `formatVersion`을 확인한 뒤 `meta` / `notes`만 소비한다.
- 로드 시 `chart.schema.json`으로 검증한다.
- SPEC의 의미론적 제약(동일 `(start, position)` 중복 금지, 같은 레인 롱노트 겹침 금지)도 로드 시 검사한다. 위반 시 로드 실패와 사유를 표시한다.
- 포맷 변경이 필요하면 `formatVersion`을 올리고 `SPEC.md`와 스키마를 함께 갱신한다. `game/`만 단독으로 포맷을 확장하지 않는다.

## 기술 스택

| 항목 | 값 |
|------|-----|
| 엔진 | Godot **4.6.3** |
| 스크립트 | GDScript |
| 파이썬 | 런타임 의존 없음 |
| 입력 | 키보드만 |
| 레인 | 3키 — 차트 `position` `0` / `1` / `2` |
| 비주얼 | 츄니즘식 3D 노트 하이웨이 (원근으로 노트가 판정선에 접근) |
| 개발 OS | Linux |
| 배포 타깃 | Windows (Godot Export) |
| 오디오 | **mp3만** (`meta.audio`가 mp3가 아니면 로드 실패) |
| 타이밍 시계 | 오디오 재생 위치 + `meta.bpm` / `meta.offsetBeats` ([SPEC 변환식](../format/SPEC.md)) |

## 차트 연동

- 입력 포맷: `format/chart.schema.json`을 만족하는 JSON (`formatVersion` 1).
- `meta.audio`는 **차트 파일 기준 상대경로**이며 확장자는 `.mp3`만 허용한다.
- 노트: `single` / `long`, `position` ∈ `{0, 1, 2}`.

### 차트 디렉터리

- 플레이 목록에 올릴 차트 루트 경로는 **게임 config**의 `chart_dir`로 읽는다.
- 기본값: 저장소 기준 `format/examples` (프로젝트에서 이 경로를 가리키도록 config 기본값을 둔다).
- 엔진은 `chart_dir` 아래의 `*.json` 차트 파일을 스캔한다.
- 경로는 이후 config만 바꿔 변경한다. 포맷·스키마는 그대로 둔다.

## 입력

### 기본 키 집합

레인마다 키 집합을 가진다. 집합 중 **아무 키나 눌러도** 해당 레인이 입력된 것으로 본다.  
같은 레인에 속한 여러 키가 동시에 눌려도 그 레인의 단일 “눌림”으로 처리한다.

| 레인 | `position` | 기본 키 |
|------|------------|---------|
| 1키 | `0` | `Q` `W` `E` `R` `A` `S` `D` `F` `Z` `X` `C` `V` |
| 2키 | `1` | `T` `Y` `U` `I` `G` `H` `J` `B` `N` |
| 3키 | `2` | `O` `P` `[` `]` `K` `L` `;` `'` `M` `,` `.` `/` |

- `K`는 3키(`position` 2)에만 속한다. 2키 기본 집합에 `K`는 없다.

### 키 설정

- 게임 설정에서 레인별 키 집합을 변경할 수 있다.
- **한 키가 두 개 이상의 레인에 속하도록 저장할 수 없다.** 충돌이면 저장을 거부하고 사유를 표시한다.
- 설정은 로컬에 저장하며 재시작 후에도 유지된다.

### 기타 키

| 동작 | 키 |
|------|-----|
| 일시정지 / 일시정지 해제 | `Esc` |

## 판정

판정 이름은 좋은 것부터 나쁜 것 순으로 다음 네 단계다.

| 표시 | 기본 허용 오차 (노트 시각 대비) | 점수 가중치 |
|------|----------------------------------|------------|
| 이야! | \|Δt\| ≤ 45 ms | 1.0 |
| 히히 | 45 ms < \|Δt\| ≤ 90 ms | 0.7 |
| 엥... | 90 ms < \|Δt\| ≤ 150 ms | 0.3 |
| Miss | \|Δt\| > 150 ms 이거나 미입력 | 0.0 |

- 위 ms 경계는 **게임 config**에서 변경할 수 있다. 이름은 고정이다.
- config에는 `judge_iya_ms`, `judge_hihi_ms`, `judge_eng_ms`를 두며, 기본값은 각각 `45`, `90`, `150`이다.
- 불변 조건: `0 < judge_iya_ms < judge_hihi_ms < judge_eng_ms`.

### 싱글 노트

- 해당 레인 키가 **눌러진 시각**으로 한 번 판정한다.
- 판정선 통과 후 `judge_eng_ms`를 넘기도록 입력이 없으면 Miss.

### 롱 노트

- **시작**: 누름 시각으로 판정 (싱글과 동일 창).
- **끝**: 손을 **떼는 시각**으로 판정 (동일 창). 박자에 맞춰 떼야 한다.
- 시작을 Miss한 뒤에도 끝 판정 오브젝트는 남으며, 끝에서 다시 판정한다.
- 홀드 중 끝 비트 이전에 손을 떼면 끝 판정은 Miss이다.
- 끝 비트를 `judge_eng_ms`보다 넘겨 떼지 않으면 끝은 Miss이다.
- 롱 노트 하나당 판정 오브젝트는 **시작 + 끝 = 2개**이다.

## 점수와 콤보

- 채보 포맷에 점수 필드를 추가하지 않는다. 점수·콤보 규칙은 **엔진(`game/`)만** 가진다.
- 한 곡의 이론상 최대 점수는 항상 **1,000,000**이다.
- 콤보는 표시만 하며 **점수에 가산하지 않는다.** Miss 시 콤보는 0으로 리셋한다. 이야! / 히히 / 엥... 은 콤보를 1 증가시킨다.
- 점수는 판정 오브젝트에만 의존한다.

### 판정 오브젝트 수

- `single` → 1  
- `long` → 2 (시작, 끝)  
- `N` = 차트 내 모든 판정 오브젝트 수. `N = 0`이면 점수는 0이다.

### 배점

1. `base = floor(1_000_000 / N)`
2. `remainder = 1_000_000 - base * N`
3. 판정 오브젝트를 차트 등장 순(동일 시각이면 `position` 오름차순, 롱은 시작이 끝보다 앞)으로 나열했을 때, **앞쪽 `remainder`개** 오브젝트의 만점 몫은 `base + 1`, 나머지는 `base`이다.
4. 오브젝트 `i`의 만점 몫을 `P_i`라 할 때, 획득 점수 기여는 `floor(P_i * weight)`이다. `weight`는 위 판정 표의 가중치다.
5. 곡 종료 점수 = 모든 기여의 합 (최대 1,000,000, 전부 이야!이면 정확히 1,000,000).

## 유저 설정 (config)

엔진은 아래 항목을 config로 읽고 쓰며, 설정 UI에서 변경 가능하게 한다.

| 키 | 의미 | 기본값 |
|----|------|--------|
| `chart_dir` | 차트 스캔 루트 | `format/examples` |
| `scroll_speed` | 노트가 다가오는 속도 배율 | `1.0` |
| `judge_iya_ms` | 이야! 상한(ms) | `45` |
| `judge_hihi_ms` | 히히 상한(ms) | `90` |
| `judge_eng_ms` | 엥... 상한(ms) | `150` |
| `lane0_keys` | `position` 0 키 목록 | 위 기본 키 집합 |
| `lane1_keys` | `position` 1 키 목록 | 위 기본 키 집합 |
| `lane2_keys` | `position` 2 키 목록 | 위 기본 키 집합 |
| `window_width` | 창 너비 | `1280` |
| `window_height` | 창 높이 | `720` |
| `fullscreen` | 전체화면 | `false` |

- `scroll_speed`는 `0.5` 이상 `3.0` 이하, 스텝 `0.05`로 제한한다.
- 해상도·전체화면은 위 기본으로 시작하고, 설정에서 바꾼다.

## 비주얼

- 3레인 3D 하이웨이. 노트가 원근감 있게 판정선으로 접근한다.
- 구현 세부는 `game/` 코드에 두며, 채보 포맷에는 연출 필드를 넣지 않는다.

## 범위

### 포함

- 차트 로드·검증·선곡·플레이
- 3키 키보드 입력 및 리맵
- 판정·점수·콤보 표시
- Esc 일시정지
- Windows export

### 포함하지 않음

- 파이썬 / 비-Godot 런타임
- 컨트롤러·터치 전용 입력
- mp3 이외 오디오
- 차트 포맷 v1에 없는 노트 타입
